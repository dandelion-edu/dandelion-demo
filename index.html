Sistema para la Gestión de Trayectorias Socioemocionales: un espacio de trabajo pensado para el Equipo de Orientación Escolar.

Te damos la bienvenida. Es la primera vez que se abre este espacio en esta computadora: creá la contraseña de acceso para tu Equipo de Orientación Escolar.

¿Olvidaste tu contraseña?

Cuidado de la información: esta contraseña es una protección simple, pensada para el uso interno del EOE en las computadoras del colegio; no reemplaza un sistema de seguridad de nivel empresarial. Los registros contienen datos sensibles de niños, niñas y adolescentes (bienestar emocional, vínculos, familia): resguardá el acceso a esta computadora y a los archivos de respaldo como corresponde a información confidencial.
